Battery Aging (Estimate)

Why this matters

Battery capacity fades over time from two combined effects: ambient temperature at the site, and how deeply the battery is cycled each day. This page projects each device's expected capacity and feasibility result forward using published, rule-of-thumb degradation figures. This is a SALA Estimate, not a manufacturer-certified prediction - see Methodology & Assumptions below.

Methodology & assumptions

Capacity fade combines two published, rule-of-thumb mechanisms: calendar aging (temperature-driven, using this site's PVGIS-derived average annual temperature) and cycle aging (depth-of-discharge-derated, using this study's simulated daily battery cycling). Figures are sourced from general battery-industry literature per chemistry, not manufacturer-specific test data - treat as an estimate for planning purposes, not a certified warranty prediction.
